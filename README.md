# mercury — liquid portfolio

Портфолио, где весь экран — живая ртуть (raymarching-шейдер на WebGL). Капли преломляют гигантскую типографику,
тянутся за курсором и разлетаются от клика. Разделы переключаются «плавлением» постера.
Внизу справа живёт маскот **Капля** — он собирает бриф и кидает заявку тебе в Telegram.
